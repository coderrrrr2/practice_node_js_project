MerchX eCommerce backend is a server-rendered web application built with Node.js and Express, designed to deliver dynamic HTML pages rather than a REST API. It leverages Sequelize ORM to interact with a PostgreSQL database, providing a robust and scalable foundation for managing users, products, orders, carts, and payments.
Unlike headless eCommerce platforms, this backend directly renders full HTML pages on the server, making it ideal for traditional eCommerce setups where SEO, initial load performance, and direct server-side templating are priorities.
🔧 Key Features:
* Server-rendered pages using templating engines like EJS or Pug
* PostgreSQL database integration with Sequelize ORM
* User authentication and session management
* Product listing, shopping cart, and order checkout
* Admin dashboard for inventory and user management
* SEO-friendly and lightweight — no front-end frameworks needed
